Build a safe bug-report packet

For developers reporting local failures, collect the logs and setup details maintainers need, then inspect every file before sharing.

  • No telemetry
  • Local review folder

02 / Method

Create a packet in four steps.

  1. 01

    Preview

    Check the TOML list. Preview reads nothing and runs no commands.

  2. 02

    Capture

    Approve supported version checks. Redact logs before saving them.

  3. 03

    Inspect

    Check each file, size, fingerprint, and redaction count.

  4. 04

    Export

    Export the inspected files as a packet ZIP.

03 / Redaction desk

Redact evidence before saving.

token=████████████

Replace common secrets

Emails, IP addresses, tokens, and home paths are replaced in copied logs.

a7f3…91cc

Record a fingerprint

Configuration items record a SHA-256 fingerprint instead of file contents.

y / N

Approve commands

Only supported version commands can run, and only after approval.

04 / The manifest

Save a collection checklist in your project.

A TOML file names each collection item. It cannot use paths outside your project.

system
Operating system and architecture
tool-version
Approved version command
config-hash
SHA-256 fingerprint only
log
Bounded, redacted text copy
environment
Named safe environment values

Run it locally

Start with the sample.

cargo install --git https://github.com/B-Divyesh/sf-dev-diagnostic-packet.git

Then run diagnostic-packet demo.
