# Changelog

All notable changes are documented here. This project follows semantic versioning.

## 0.1.1 — 2026-08-28

- Fix the documented default CLI flow when the manifest is a bare filename.
- Precache the generated documentation shell so an activated site reloads offline.
- Add static-host cache and browser-policy headers for the documentation site.

## 0.1.0 — 2026-08-27

- Initial local-first manifest, preview, capture, inspection, and ZIP export workflow.
- Built-in redaction for tokens, email addresses, IP addresses, and home paths.
- Self-contained HTML and JSON packet reports.
- Static documentation site with an interactive sample packet walkthrough.
